# 美股行业 ETF 滚动总回报

公开静态页面，展示 11 只美国行业 ETF 在 1、3、6、9、12 个月窗口上的分红再投资总回报，以及它们在这 11 只之内的排名。

线上地址：<https://runninghero.github.io/lianghua/>

## 页面

标的为标普行业 SPDR：

| 代码 | 行业 | 代码 | 行业 |
| --- | --- | --- | --- |
| XLB | 原材料 | XLP | 必需消费 |
| XLC | 通信服务 | XLRE | 房地产 |
| XLE | 能源 | XLU | 公用事业 |
| XLF | 金融 | XLV | 医疗 |

正收益为绿色，负收益为红色。点击表头可以改排序。默认按 9 个月收益从高到低排列。页眉标出所用的最近美股收盘日，以及页面更新时间（亚洲/上海，UTC+8）。

## 计算方法

- 收益是分红再投资后的总回报，价格用 Yahoo Finance 的复权收盘价（adjusted close）。
- 终点 T 是这 11 只都能取到的最近一个已收盘美股交易日。
- N 个月收益的日历锚点是 T 减去 N 个日历月。目标月份天数更少时，把日钳到该月最后一天（例如 3 月 31 日减 1 个月，为 2 月 28 日或 29 日）。
- 起点是该 ETF 在锚点当日或之前的最后一个交易日。
- 收益率 = 复权收盘价(T) / 复权收盘价(起点) − 1。
- 若某只 ETF 在起点当日及之前没有价格，该窗口显示 n/a，并且不进入该窗口的排名。目前这 11 只都已有超过 12 个月的历史，这条只是保护。
- 排名只在这 11 只之间计算。收益相同则并列，名次取最小排名（1 为最高）。

数字由 `scripts/update.py` 从拉取到的复权价计算，不在页面里写死。结果写在 `data/returns.json`，页面用相对路径 `./data/returns.json` 读取。

## 更新频率

GitHub Actions 工作流 `.github/workflows/update-and-deploy.yml`：

- 定时：`0 22 * * 1-5`，即周一至周五 22:00 UTC，对应亚洲/上海时间周二至周六 06:00。11 月美国处于东部标准时间，美股 16:00 ET 收盘是 21:00 UTC，22:00 UTC 留出数据入库的缓冲。
- 也可在仓库的 Actions 页面手动运行，或在推送到 `main` 时运行（仅更新 `data/returns.json` 的提交不会再次触发，以免循环）。
- 工作流重新拉取行情、重算 JSON、把 JSON 提交回 `main`，并用 GitHub Pages（Actions 源）发布静态页。

若在美股现金交易时段手动运行，脚本会先丢掉尚未收盘的当日 K 线，终点仍用上一个完整交易日。

## 本地重算

只使用 Python 标准库：

```bash
python3 scripts/update.py
```

成功后覆盖 `data/returns.json`。
